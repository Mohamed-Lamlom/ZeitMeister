# ZeitMeister

**An interactive tool for practicing German time expressions.**

ZeitMeister helps German learners read and express time through an interactive analog clock and short practice exercises.

## Features

- **Three practice modes:** Read, Type, and Reverse
- **Two time styles:** *Inoffiziell* and *Offiziell*
- Adjustable clock and time difficulty
- Interface available in Arabic, English, and German
- Immediate answer feedback, scores, streaks, and progress statistics
- Light and dark themes
- Offline use through the standalone HTML version or cached app files after the hosted site has been opened online

## Privacy and storage

ZeitMeister requires no account or backend. Settings and progress are stored locally in the browser on the current device and are not synchronized between devices.

## Technology

Built with HTML, CSS, and vanilla JavaScript. No build step or third-party runtime dependencies are required.
